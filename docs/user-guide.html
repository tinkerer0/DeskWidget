DeskWidget 사용 설명서

안 읽어도 쓸 수 있게 만들었습니다. 급하면 아래 두 단계만 하고 넘어가세요.

1

사진 넣기

사진을 넣으면 위젯이 됩니다 폴더에 원하는 사진(PNG·JPG·WebP·GIF)을 넣습니다.

2

실행하기

DeskWidget 실행.exe를 더블클릭합니다.

위젯 다루기

  • 이동(드래그): 위젯을 마우스 왼쪽 버튼으로 누른 채 끌면(드래그하면) 옮겨집니다.
  • 크기 조절: 마우스 커서를 위젯 위에 올린 상태에서 휠을 위로 굴리면 커지고 아래로 굴리면 작아집니다. 위젯을 먼저 클릭할 필요는 없으며, 바탕화면 빈 곳에서 굴린 휠에는 반응하지 않습니다.
  • 메뉴: 위젯을 오른쪽 클릭하면 크기 초기화, 위젯끼리 앞뒤 순서 바꾸기, 숨기기, 폴더 열기, 새로고침, 전체 종료를 고를 수 있습니다.
  • 종료: 화면 오른쪽 아래 트레이 아이콘을 오른쪽 클릭해 종료를 누르거나, 단축키 Ctrl+Alt+Q를 씁니다.

알아두면 좋은 것

  • 자동 시작: 컴퓨터 켤 때 같이 켜지는 기능은 기본적으로 꺼져 있습니다. 트레이 메뉴에서 부팅 시 시작을 직접 켜야 동작합니다.
  • 지원 형식: PNG, JPG(JPEG), WebP, GIF만 위젯으로 만들 수 있습니다.
  • 개수 제한: 폴더 안 사진은 한 번에 최대 100개까지만 위젯으로 표시됩니다.
  • 로컬 처리: 인터넷으로 사진을 전송하거나 외부 서버와 통신하지 않습니다. 모든 처리는 이 컴퓨터 안에서만 이뤄집니다.
  • 설정 저장 위치: 위젯 위치·크기·순서 같은 설정은 %APPDATA%\DeskWidget 폴더에 저장됩니다. 이 폴더가 OneDrive 등으로 다른 PC와 동기화되도록 설정돼 있다면, 설정도 같이 동기화될 수 있습니다.
  • PowerShell 사용: 위젯을 바탕화면 맨 뒤로 배치하거나 자동 시작을 켜고 끌 때, 이 컴퓨터에 이미 있는 PowerShell을 로컬에서만 짧게 실행합니다. 인터넷에 접속하거나 외부로 무언가를 보내지 않습니다.

사진과 설정은 전부 이 컴퓨터 안에만 남습니다. 지우고 싶으면 압축 풀었던 폴더를 통째로 삭제하면 됩니다. 설정 기록까지 지우려면 %APPDATA%\DeskWidget 폴더를 추가로 삭제하세요.

DeskWidget — 이 문서는 인터넷 연결이나 별도 프로그램 없이 이 파일 하나로 전부 표시됩니다.
